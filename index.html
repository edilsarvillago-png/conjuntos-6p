Tema: Teoría de Conjuntos

Fundamentos de la Teoría de Conjuntos

Comprende cómo agrupar, contar y nombrar elementos de manera matemática.

1. Conjuntos y Elementos

Un Conjunto es una colección bien definida de objetos llamados elementos. Los conjuntos se nombran con letras mayúsculas ($A, B, C$) y sus elementos se encierran entre llaves $\{ \}$.

Pertenencia ($\in$ y $\notin$):

Si un objeto está dentro del conjunto: $x \in A$ (Pertenece).

Si un objeto no está en el conjunto: $y \notin A$ (No pertenece).

2. Cardinalidad de un Conjunto

La cardinalidad es la cantidad total de elementos diferentes que posee un conjunto. Se denota como $n(A)$ o $|A|$.

Ejemplo 1: Si $A = \{a, e, i, o, u\}$, entonces $n(A) = 5$.

Ejemplo 2: Si $B = \{2, 2, 4, 6\}$, sin repetir $B = \{2, 4, 6\}$, por lo que $n(B) = 3$.

3. Formas de Representar un Conjunto

Por Extensión (o Tabular)

Se listan o enumeran explícitamente todos sus elementos uno por uno.

$A = \{1, 3, 5, 7, 9\}$
Por Comprensión (o Constructiva)

Se menciona la característica común que cumplen todos los elementos ($x / x...$).

$A = \{x / x \text{ es impar}, x < 10\}$
Forma Gráfica (Diagrama de Venn)

Se representan los elementos mediante puntos dentro de un área cerrada.

4. Clases de Conjuntos según su Cardinalidad

Conjunto Vacío No posee elementos. Cardinalidad $n = 0$. Símbolo: $\emptyset$ o $\{\}$.
Conjunto Unitario Tiene un solo elemento. Cardinalidad $n = 1$. Ejemplo: $\{0\}$.
Finito vs. Infinito Finito: Se pueden contar todos.
Infinito: No tiene fin en el conteo.

Ejemplos Resueltos Paso a Paso

Revisa la conversión entre formas de representación y el cálculo de cardinalidad.

NIVEL BÁSICO (5 Ejemplos)

1. Determinar cardinalidad: Halla $n(A)$ para $A = \{m, a, t, e, m, a, t, i, c, a, s\}$.

Solución: Eliminamos repetidos: $A = \{m, a, t, e, i, c, s\}$. Contamos elementos únicos. Resultado: $n(A) = 7$.

2. Expresar por extensión: $B = \{x / x \text{ es vocal de la palabra "COLEGIO"}\}$

Solución: Vocales sin repetir: $B = \{O, E, I\}$.

3. Pertenencia: Dado $C = \{2, 4, 6, 8\}$, evalúa si $5 \in C$ o $5 \notin C$.

Solución: El número 5 no está en el conjunto C, por lo que: $5 \notin C$.

4. Expresar por comprensión: $D = \{\text{Lunes, Martes, Miércoles, Jueves, Viernes, Sábado, Domingo}\}$

Solución: Característica común: $D = \{x / x \text{ es un día de la semana}\}$.

5. Clasificar conjunto: Halla la cardinalidad de $E = \{x / x \text{ es un mes con 35 días}\}$.

Solución: Es un conjunto vacío $E = \emptyset$, por lo tanto $n(E) = 0$.

NIVEL INTERMEDIO (5 Ejemplos)

1. De comprensión a extensión: $F = \{x / x \in \mathbb{N}, 3 < x \le 8\}$

Solución: Mayor que 3 y menor o igual a 8: $F = \{4, 5, 6, 7, 8\}$. Cardinalidad: $n(F) = 5$.

2. Por comprensión: $G = \{5, 10, 15, 20, 25\}$

Solución: Múltiplos de 5 menores o iguales a 25: $G = \{x / x \text{ es múltiplo de } 5, 0 < x \le 25\}$.

3. Diagrama de Venn: Dado $H = \{1, 2, 3, 4\}$ y $I = \{3, 4, 5, 6\}$.

Solución: Se ubican en la intersección los elementos comunes $\{3, 4\}$. En el área exclusiva de $H$ va $\{1, 2\}$, y de $I$ va $\{5, 6\}$.

4. Cardinalidad con fórmula: $J = \{x+1 / x \in \mathbb{N}, x < 5\}$

Solución: Valores de $x$: $1, 2, 3, 4$. Evaluando $x+1$: $J = \{2, 3, 4, 5\}$. Por lo tanto, $n(J) = 4$.

5. Clasificación: $K = \{x / x \text{ es un número primo par}\}$

Solución: El único primo par es el 2: $K = \{2\}$. Es un Conjunto Unitario ($n(K) = 1$).

NIVEL AVANZADO (5 Ejemplos)

1. Hallar la suma de elementos: $L = \{2x / x \in \mathbb{N}, 2 \le x < 6\}$

Valores de $x$: $2, 3, 4, 5$. Calculamos $2x$: $L = \{4, 6, 8, 10\}$. Suma = $4 + 6 + 8 + 10 = \mathbf{28}$.

2. Igualdad de conjuntos: Si $M = \{a+2, 8\}$ y $N = \{10, b-3\}$ son iguales.

$a + 2 = 10 \Rightarrow a = 8$. Además $b - 3 = 8 \Rightarrow b = 11$. El valor de $a + b = 8 + 11 = \mathbf{19}$.

3. Transformación: $P = \{x^2 - 1 / x \in \mathbb{N}, 1 \le x \le 4\}$

Evaluamos $x = 1, 2, 3, 4$: $1^2-1=0$, $2^2-1=3$, $3^2-1=8$, $4^2-1=15$. Extensión: $P = \{0, 3, 8, 15\}$. Cardinalidad $n(P) = 4$.

4. Cuadrados perfectos por comprensión: $Q = \{1, 4, 9, 16, 25, 36\}$

Son los valores de $x^2$ para $x \in \{1, 2, 3, 4, 5, 6\}$. Por comprensión: $Q = \{x^2 / x \in \mathbb{N}, 1 \le x \le 6\}$.

5. Múltiple condición: $R = \{x / x \in \mathbb{N}, x \text{ es impar}, 10 < x < 20\}$

Impares entre 10 y 20: $R = \{11, 13, 15, 17, 19\}$. Cardinalidad: $n(R) = 5$.

Ejercicios Prácticos para Resolver

Trabaja en tu cuaderno y presiona el botón para comprobar tus resultados.

Nivel Básico

1. Dado el conjunto $A = \{a, e, i, o, u\}$, ¿cuál es su cardinalidad $n(A)$?

Respuesta: $n(A) = 5$. Posee 5 elementos correspondientes a las vocales del abecedario.

2. Expresa por extensión el conjunto de vocales de la palabra "GUATEMALA".

Respuesta: Sin repetidos: $\{U, A, E\}$.

3. Dado $B = \{1, 3, 5, 7\}$, indica si es Verdadero o Falso: $4 \in B$.

Respuesta: FALSO. El número 4 no pertenece a $B$ ($4 \notin B$).

4. Expresa por comprensión el conjunto $C = \{\text{Primavera, Verano, Otoño, Invierno}\}$.

Respuesta: $C = \{x / x \text{ es una estación del año}\}$.

5. ¿Cuál es la clase de conjunto de $D = \{x / x \text{ es un perro que habla francés}\}$?

Respuesta: Conjunto VACÍO ($\emptyset$), ya que ningún elemento cumple dicha condición.

Nivel Intermedio

6. Expresa por extensión: $E = \{x / x \in \mathbb{N}, x \text{ es par}, 2 \le x \le 12\}$

Respuesta: $E = \{2, 4, 6, 8, 10, 12\}$.

7. Halla $n(F)$ para $F = \{x+2 / x \in \mathbb{N}, 1 \le x < 6\}$.

Valores de $x$: $1, 2, 3, 4, 5$.
Sumando 2 a cada uno: $F = \{3, 4, 5, 6, 7\}$.
Respuesta: $n(F) = 5$.

8. Expresa por comprensión el conjunto $G = \{10, 20, 30, 40, 50\}$.

Respuesta: $G = \{x / x \text{ es múltiplo de 10}, 10 \le x \le 50\}$.

9. Clasifica el conjunto $H = \{x / x \in \mathbb{N}, 7 < x < 8\}$.

Respuesta: Conjunto VACÍO ($\emptyset$), no existe un entero natural entre 7 y 8.

10. Representa gráficamente los conjuntos $A=\{1, 2, 3\}$ y $B=\{3, 4, 5\}$. ¿Qué elemento se ubica en el centro de la intersección?

Respuesta: El número 3, ya que pertenece a ambos conjuntos al mismo tiempo ($3 \in A$ y $3 \in B$).

Nivel Avanzado

11. Si $M = \{2x + 1 / x \in \mathbb{N}, 3 \le x < 7\}$, determina la suma de sus elementos.

$x = 3, 4, 5, 6$.
$2(3)+1 = 7, 2(4)+1 = 9, 2(5)+1 = 11, 2(6)+1 = 13$.
$M = \{7, 9, 11, 13\}$.
Suma: $7 + 9 + 11 + 13 = \mathbf{40}$.

12. Los conjuntos $P = \{2a - 4, 12\}$ y $Q = \{10, b + 5\}$ son unitarios. Halla $a + b$.

Como P es unitario: $2a - 4 = 12 \Rightarrow 2a = 16 \Rightarrow a = 8$.
Como Q es unitario: $b + 5 = 10 \Rightarrow b = 5$.
Resultado: $a + b = 8 + 5 = \mathbf{13}$.

13. Transforma a extensión $R = \{x^3 / x \in \mathbb{N}, 1 \le x \le 4\}$.

$1^3 = 1, 2^3 = 8, 3^3 = 27, 4^3 = 64$.
Respuesta: $R = \{1, 8, 27, 64\}$.

14. Expresa por comprensión: $S = \{2, 5, 10, 17, 26\}$.

$1^2+1=2, 2^2+1=5, 3^2+1=10, 4^2+1=17, 5^2+1=26$.
Respuesta: $S = \{x^2 + 1 / x \in \mathbb{N}, 1 \le x \le 5\}$.

15. Halla la cardinalidad de $T = \{x / x \text{ es una cifra del número } 33887755\}$.

Cifras distintas: $T = \{3, 8, 7, 5\}$.
Respuesta: $n(T) = 4$.

Cuestionario Breve de Comprobación

1. ¿Cuál es la cardinalidad del conjunto $A = \{x / x \text{ es vocal de la palabra "BANANA"}\}$?

Respuesta: $n(A) = 1$. La única vocal es 'A'. Al no contar elementos repetidos, la cardinalidad es 1.

2. Si $B = \{2, 4, 6, 8\}$, ¿cuál es su representación POR COMPRENSIÓN?

Respuesta: $B = \{x / x \text{ es número par}, 2 \le x \le 8\}$. Define la regla o condición matemática común.

3. ¿Qué símbolo matemático expresa que un elemento forma parte de un conjunto?

Respuesta: $\in$. Simboliza "pertenece a".
